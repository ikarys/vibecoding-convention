# Vibecoding declaration

This repository follows the [Vibecoding Convention](CONVENTION.md).

- **Level claimed:** 1, Declared. This repository holds text and agent
  definitions, with no code to test yet. The level will be revised when
  tooling with executable code is added.
- **AI assistance:** most of the text is drafted by AI assistants and reviewed,
  edited and decided by the maintainer. Tools and models so far: Claude Code
  (Claude Fable 5.1, Claude Opus 5.5), a local Qwen model through Fennec for
  bulk drafting.
- **Share of AI-written content:** most of it.
- **Maintainer who reviews and decides:** Ikarys.
- **Review policy:** single maintainer. Every change is read by the maintainer
  before it reaches `main`. AI-written commits carry a `Co-Authored-By:` trailer
  naming the model.
- **Adopted at commit:** the first commit of this repository.
